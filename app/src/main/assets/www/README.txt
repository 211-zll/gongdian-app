供电工区工作台（手机 APP）
============================

本应用是飞书妙搭「供电工区工作台」的本地复刻版，作为手机 APP 使用。
无需登录即可增删改查所有数据，数据保存在当前设备的浏览器中。

一、Supabase 云端同步（推荐）
------------
1. 打开 Supabase 控制台，进入你的项目 -> SQL Editor，执行本应用目录下的
   supabase_setup.sql（建 2 张表：gd_accounts 账号表、gd_user_data 用户数据表）。
2. 打开 Supabase 项目 -> Project Settings -> API，复制：
   - Project URL（如 https://xxx.supabase.co）
   - anon public key
3. 打开应用 -> 「数据管理」->「云端同步（Supabase）」，
   粘贴 URL 和 Key，点「保存并启用」->「测试连接」（提示连接成功即可）。
4. 之后注册/登录的账号和全部数据都保存在 Supabase 云端，
   在任何浏览器登录同一账号都能看到全部数据，修改自动同步。
   （数据会先缓存到本地，随后自动上传云端）
5. 安全说明：当前使用 anon key + 关闭 RLS，适合内部使用；
   如需更强安全，建议改用 Supabase Auth + RLS（可联系开发者加固）。

二、账号登录
------------
- 首次打开需注册账号（用户名/密码，可选手机号），或使用手机验证码登录。
- 数据按账号隔离保存，勾选"记住密码"后重新打开浏览器自动登录；
  不勾选则关闭浏览器后需重新登录。
- 换浏览器/设备：在旧浏览器「数据管理-导出备份」下载 JSON（含账号和全部数据），
  在新浏览器打开应用后「数据恢复」导入，会自动恢复账号并登录，原密码即可查看全部数据。
- 注：应用为纯静态网页（无服务器），无法自动云端同步；
  账号与数据保存在本机浏览器，跨浏览器需通过上面的备份/恢复迁移。

二、如何运行
------------
方法一（最简单）：直接用手机/电脑浏览器打开 index.html 文件即可使用。
方法二（推荐，支持离线/PWA）：把整个 app 文件夹放到任意静态服务器
（例如 python -m http.server、nginx、或手机上的静态托管工具），
然后用浏览器访问 http://服务器地址/ 即可。此时可将应用“添加到主屏幕”，
像原生 APP 一样使用，且支持离线缓存。

二、功能清单
------------
1. 工作台（首页）
   - 统计卡片：工区人员、今日值班、今日待办
   - 今日值班人员展示、今日待办快捷勾选
   - 快捷操作入口、近 4 天排班预览

2. 花名册
   - 人员增删改查：姓名、职名、身份证号（自动算年龄）、手机号、
     家庭住址、健康状况、入路时间、技能等级
   - 排序（默认/姓名/职名/年龄）、上移/下移
   - Excel 导入导出（.xlsx）、导入模板下载

3. 排班表
   - 月历网格：行=人员，列=日期
   - 班次：休 / 白 / 值 / 年休 / 学 / 差
   - 从花名册添加人员、上移/下移/删除
   - 生成默认排班、导入排班（覆盖/填充）、导出 Excel、导出图片

4. 工分统计
   - 月网格编辑每人每日工分、合计
   - 当日事由编辑、工分排名
   - 导出 Excel

5. 待办 & 备忘录
   - 待办：标题、描述、优先级（高/中/低）、截止日期、重要标记、完成状态
   - 备忘录：标题、内容、分类（工作笔记/密码记录/物品登记/会议记录）、重要标记
   - 筛选、搜索、排序、导出 JSON

6. 设备资料
   - 设备总览（分类统计 + 设备图纸导入）、区间、站区、设备管理
   - 设备图纸：支持导入 CAD（.dwg/.dxf）、PDF、Word、Excel、PPT、图片等格式并显示/下载
   - 设备分类：配电所、远动房、箱变、架空线、电抗器、对接箱、分支箱、变压器、其他
   - 架空线支持杆型：隔离杆、直线杆、耐张杆、电缆杆、跨越杆
   - 设备字段：分类/杆型/型号/参数/维护记录/经纬度导航
   - 设备照片支持从本地上传（自动压缩）或粘贴链接；一次接线图支持本地上传或链接
   - 相册：多级相册、照片上传（自动压缩）、重命名、删除、搜索
   - 导出 JSON

7. 学习资料
   - 分类：安全规章/技术标准/作业指导书/培训课件
   - 文件类型：PDF/Word/Excel/PPT/图片/视频/文本
   - 支持从本地选择文件添加（也可填文件链接）、学习进度调节、学习记录、打开/下载/分享

8. 数据管理（底部导航「数据」）
   - 导出全部数据为 JSON 备份
   - 从备份文件恢复数据
   - 一键重置所有数据
   - 安装到主屏幕引导

底部导航共 8 个入口：工作台 / 花名册 / 排班 / 工分 / 待办 / 设备 / 学习 / 数据，
所有功能一键直达。

三、数据说明
------------
- 所有数据编辑后自动保存到本机浏览器（无需手动保存，保存后顶部会短暂显示"已自动保存"）。
- 换浏览器 / 设备迁移：在「数据」页点「导出备份」下载 JSON 文件，把备份文件连同本应用
  一起复制到新设备，打开后在「数据」页点「数据恢复」导入即可，数据完整保留。
- 清除浏览器缓存会清空数据，请定期导出备份。
- 照片会上传时自动压缩后保存，受浏览器 5MB 存储限制，请定期导出备份。
